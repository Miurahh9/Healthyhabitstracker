Daily Check is a simple, private habit tracker. It asks a few yes/no questions each day (and, on the day you choose, a weekly set too), and keeps a record you can look back on.

All your data — questions, answers, and settings — stays on this device only, saved in your browser's local storage. Nothing is sent to any server, and no account is required.

Export Data lets you save or email a backup whenever you like; Import Data loads one back in.

Made with AI, Non profit.
